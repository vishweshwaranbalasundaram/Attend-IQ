# Attend-IQ Testing

## Unit Tests

Run from the `java-attendance` project directory with JDK 25 and Maven 3.9 or newer:

```powershell
mvn clean test
mvn clean verify
```

Unit tests cover attendance and student validation, report calculations, console input/rendering, CSV output, bulk-marking results, password hashing, and the five-failure/five-minute lockout policy. `LoginAttemptPolicyTest` uses a mutable fake `Clock`; it does not need MySQL.

JaCoCo writes HTML and XML reports under `target/site/jacoco/`. The report is generated by `mvn clean verify` and includes line coverage for each class. GitHub Actions prints per-service line coverage and enforces a 70% aggregate line-coverage target across classes whose names end in `Service`.

## MySQL Integration Tests

The MySQL integration tests are enabled only when `ATTENDIQ_RUN_MYSQL_IT=true`. They refuse to run unless the connected database name ends in `_test`. GitHub Actions starts MySQL 8.4, loads `src/test/resources/schema-test.sql`, and runs both integration test classes.

For a local integration run, create the isolated `attendiq_java_test` database by executing `src/test/resources/schema-test.sql`, then set these variables in PowerShell:

```powershell
$env:ATTENDIQ_DB_URL = 'jdbc:mysql://localhost:3306/attendiq_java_test?useSSL=false&allowPublicKeyRetrieval=true&serverTimezone=UTC'
$env:ATTENDIQ_DB_USER = 'YOUR_TEST_DB_USER'
$env:ATTENDIQ_DB_PASSWORD = 'YOUR_TEST_DB_PASSWORD'
$env:ATTENDIQ_RUN_MYSQL_IT = 'true'
mvn clean verify
```

`AttendanceMySqlIntegrationTest` exercises attendance persistence, transactional audit history, concurrent duplicate rejection, enrollment rules, dashboard queries, and protected deletes. `FacultyAuthServiceIntegrationTest` covers correct and wrong passwords, an unknown faculty ID, a null password hash, lockout persistence, and password-free authentication audit records. Do not point these tests at `attendiq_java`, a personal database, or production.

## Start MySQL with Docker Compose

From the `java-attendance` directory, set a local-only password and start the sole Compose service:

```powershell
$env:ATTENDIQ_DB_PASSWORD = Read-Host 'Enter a local-only MySQL password'
docker compose up -d mysql
```

The MySQL image loads `src/main/resources/schema.sql` on first initialization. The script includes demo rows. Keep `ATTENDIQ_DB_PASSWORD` in the local environment; do not commit it. When the database is ready, configure the same password as `ATTENDIQ_DB_PASSWORD`, set `ATTENDIQ_DB_USER=root`, and run `mvn exec:java`.

To stop MySQL, run `docker compose down`. The named volume preserves the database; `docker compose down -v` deletes it.
